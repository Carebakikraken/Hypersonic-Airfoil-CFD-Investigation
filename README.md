# Hypersonic Airfoil CFD Investigation

## Overview
Comparative CFD analysis of Double-Wedge, Bi-Convex, and Dome airfoils under Mach 1–6 flow conditions using ANSYS Fluent.

## Objectives
- Analyse shockwave behaviour
- Compare drag characteristics
- Validate solver stability
- Investigate aerodynamic optimisation

## Software Used
- ANSYS Fluent
- SolidWorks
- MATLAB

## Key Features
- Mesh independence study
- Pressure contour analysis
- Compressible flow modelling
- Solver convergence validation

## Results
- Reduced drag using sharp leading-edge geometry
- Validated CFD stability across hypersonic conditions
- Compared aerodynamic efficiency between airfoil configurations
